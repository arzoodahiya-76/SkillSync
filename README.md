# SkillSync
## Don’t just claim your skills. Prove them.
**SkillSync** is an AI-powered competency intelligence platform developed for **Smart India Hackathon 2026 – Problem Statement SIH26134**.
It addresses the challenge of aligning **skill development programs with industry requirements and emerging job-market demands** by creating a continuous evidence-based loop between:
> **Industry Requirements → Student Competencies → Skill Gaps → Targeted Development → Reassessment → Opportunity Alignment**
SkillSync goes beyond resume-based or self-reported skill matching. It evaluates whether a student can actually demonstrate the competencies they claim and continuously identifies the skills that need improvement.

# 🎯 The Problem
The skill ecosystem currently operates in disconnected layers.
```text
INDUSTRY
   ↓
Requires specific and evolving skills
INSTITUTIONS
   ↓
Provide education and training
STUDENTS
   ↓
Learn skills and claim competencies
RECRUITERS
   ↓
Try to determine whether those skills are actually demonstrated

The problem is not simply that students lack skills.

The deeper problem is the absence of a reliable mechanism to continuously answer:

* What skills does the industry currently require?
* What competencies does a student actually possess?
* How reliable is a student’s claimed proficiency?
* Where is the exact skill gap?
* What should the student learn next?
* Did the intervention actually improve the competency?
* Are institutions developing the skills industry needs?
* Can recruiters identify candidates using demonstrated capability rather than claims alone?

The central issue:

Skill claims do not necessarily equal skill evidence.

A student may claim:

Python — Advanced

But a resume alone cannot establish whether the student can actually:

* solve programming problems,
* write efficient code,
* understand Python concepts,
* build practical applications,
* explain technical decisions,
* or apply Python in a real-world situation.

SkillSync addresses this missing layer.

SkillSync creates an evidence-based competency intelligence layer connecting:

Industry ↔️ Institution ↔️ Student

Instead of treating skills as static profile fields, SkillSync treats them as competencies that can be measured, validated, improved and reassessed.

The platform combines different forms of evidence to create a more reliable competency profile.

🚀 What Makes SkillSync Different?

SkillSync is not another job portal, resume builder or course platform.

The key innovation is the layer between:

What industry requires

and

What a student claims to know

and

What the student can actually demonstrate.

1. Evidence over claims

A claimed skill is not automatically treated as a validated skill.

2. Competency over keywords

Instead of relying only on keyword matching, SkillSync maps requirements and evidence to a structured competency taxonomy.

3. Multi-modal evidence

Competencies can be supported by:

* Technical assessments
* Practical tasks
* Projects
* Resume evidence
* GitHub/project evidence
* AI interviews
* Verified credentials
* Real-world feedback

4. Closed-loop skill development

The platform doesn’t stop after identifying a gap.

It follows:

Measure → Identify → Learn → Demonstrate → Reassess

5. Industry feedback reaches skill development

The system is designed to help institutions understand which competencies are increasingly required and where students are falling short.

⚙️ Setup

1. Clone the repository

git clone https://github.com/arzoodahiya-76/SkillSync.git
cd SkillSync

⸻

2. Create a virtual environment

macOS / Linux

python3 -m venv venv
source venv/bin/activate

Windows

python -m venv venv
venv\Scripts\activate

⸻

3. Install dependencies

pip install -r requirements.txt

⸻

4. Configure environment variables

Create a .env file in the project root.

AI_PROVIDER=gemini
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-3.6-flash

Optional OpenAI configuration:

OPENAI_API_KEY=your_openai_api_key
OPENAI_MODEL=your_openai_model

Security

Never commit API keys to GitHub.

The .env file should remain local and must not be pushed to the repository.

⸻

▶️ Run the Application

Start the Flask application:

python3 app.py

The application will be available at:

http://127.0.0.1:5000

Open the address in a browser.

🔐 Security & Reliability

SkillSync follows a provider-independent and server-side AI architecture.

Key principles:

* API keys are stored in environment variables.
* API credentials are never exposed to frontend JavaScript.
* AI calls are handled by the backend.
* User inputs are validated.
* AI extraction is separated from deterministic competency evaluation.
* .env is excluded from Git.
* Provider failures return explicit errors instead of fabricated AI responses.
